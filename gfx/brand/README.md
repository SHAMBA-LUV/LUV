# Brand marks

`uniswap_horizontal_pink.svg`, `uniswap_horizontal_white.svg`, `uniswap_icon_pink.svg`, `uniswap_icon_white.svg` are the
official Uniswap marks, byte-identical (line endings aside) to `Uniswap Brand Assets/Uniswap_{horizontallogo,icon}_{pink,white}.svg`
in the official kit, [Uniswap/brand-assets](https://github.com/Uniswap/brand-assets) @ `1d82991`. Use per the kit's
Brand Guidelines and the [Trademark Policy](https://uniswap.org/trademark): never alter the files, no containers or
added elements, pink on neutral backgrounds (white only on dark), keep clear space, never imply affiliation or
endorsement. Uniswap pink `#FC72FF`; accessible pink `#F50DB4` for small marks on light backgrounds.

`etherscan_wordmark_*.svg` and `metamask-fox.svg` are those projects' own marks, used to link to them.
